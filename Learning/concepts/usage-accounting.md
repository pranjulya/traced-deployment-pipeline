# Unknown is a valid accounting state

A provider can complete after the client times out. Local transaction success cannot prove remote billing. Record pending before dispatch, complete from usage evidence, and reconcile unresolved attempts. Retries can incur multiple charges. Exact decimal arithmetic prevents floating-point drift but does not fix missing price or token evidence.
